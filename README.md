Описание

Игрок начинает с клетки 1 и должен попасть ровно на клетку 8, чтобы найти сокровище.

За один ход можно переместиться:

- на 1 клетку вперёд;
- на 2 клетки вперёд;
- на 1 клетку назад.

На игру даётся максимум 5 ходов. Нельзя выйти за пределы клеток от 1 до 10.

Возможности игры

- Начать игру
- Посмотреть правила
- Выбрать ход
- Проверять правильность ввода
- Отслеживать текущую позицию игрока
- Победить при попадании на клетку 8
- Завершить игру

Как запустить

Запустить файл с программой:

python main.py

Управление

В главном меню:

- "1" — начать игру
- "2" — посмотреть правила
- "0" — выйти

Во время игры:

- "1" — шаг вперёд
- "2" — шаг вперёд на 2 клетки
- "-1" — шаг назад

Цель игры

Попасть ровно на клетку 8 не более чем за 5 ходов.
